# v0.7.0-rc.4: protected source literals

结论：**翻译模型现在能看到一部分此前被占位符隐藏的原页公式/脚注内容；无法可靠恢复的内容不会被猜测，也不会再被自动判为内容通过。整页译稿仍不能正式使用。**

## 原问题和本轮改动

BabelDOC 捕获的原文可能只包含 `P(X <b1>)`，而 PDF 原页实际是 `P(X = 1)`。此前模型只看见保护标记，可能无法理解这个等式。新流程在确认源 PDF 哈希和页集后，使用捕获片段两侧的原文锚点，从原页可提取文字中寻找唯一、短且可信的占位内容。得到的 `=1` 等值放在独立的只读提示区；模型仍须原样返回标记，公式在 PDF 中仍由原对象保留。

歧义、低置信坐标、缺少锚点或无法从 PDF 文字层读取的内容不补猜。未恢复的公式标记触发 `needs_review`，并与已知提示一起写入 `content-review.jsonl`。新增提示同时计入输入费用估算和翻译缓存身份；重用旧捕获时不覆盖原 `units.jsonl` 或 `capture-map.jsonl`。

## 离线证据

- 原文件 `pdf/dm.pdf` 的 SHA-256 仍为 `297196f2cad5ab23cf4855f815fd69e7b7b9ee9c31255f743b668416677ad24e`。
- 第 42 页的 21 个捕获片段中，6 个片段恢复了 11 处可读提示，包括 `=1`、`=0`、`0≤`、`≤1` 和脚注编号。18 个翻译单元中仍有 9 个单元、16 个公式类标记缺少可读内容，需要原页复核。
- 既有三页 smoke 捕获：77 个片段，59 个带标记；7 个片段恢复 15 处提示。另一个独立的 12 页 development 捕获：123 个片段，59 个带标记；27 个片段恢复 63 处提示。这两个捕获集不能合并当作 200 个独立页样本。
- 抽查了概率公式、信念向量与 `P≠NP`；PDF 数学字体把 `≠` 提取成组合斜杠加等号时，提示会规范为 `≠`。这些离线提示没有经过全量人工公式逐字核对，不等于公式语义已经验收。
- 本轮**没有付费 API 调用**，也没有改写任何源 PDF 或冻结捕获。

## 下一道门

用新的提示进行受预算控制的译文验证，并把完整原文/译文交给独立双语复核；排版方面仍要实现行内公式保留与中文跨行重排，再证明整页及整本覆盖。既有 rc.3 的局部写回页不能被视为正式译本。
