# v0.6.0-rc.2 controlled A/B readiness

## Outcome

The candidate is ready for a separately authorized paid development A/B. No API call was made while preparing or accepting this candidate, and frozen-test pages were not accessed.

## Controlled comparison

- Input is the existing 12-page development capture: 121 units, of which 117 are billable and 4 are protected passthrough.
- Both arms use `deepseek-flash`, the same prompt revision, adapter revision, common style, pricing and adaptive output policy.
- The fixed arm receives only the common style. The context arm receives that same style plus neighboring source excerpts.
- The dedicated context database contains one approved document style and no glossary, semantic-memory or translation-memory entries. Preparation rejects those confounders if later introduced.
- Unit-file SHA-256 and payload/config hashes are frozen in `reports/v0.6_ab_manifest.json`.

## Cost and safety gates

- Adaptive reserved output tokens: 48,414 per arm, down from the previous fixed reservation of 234,000.
- Fixed-arm one-pass ceiling: USD 0.0865686.
- Context-arm one-pass ceiling: USD 0.0972111.
- Combined one-pass ceiling: USD 0.1837797, or CNY 1.378348 at the control rate of 7.5 CNY/USD.
- Planned hard cap: USD 0.20 / CNY 1.50, split equally between arms.
- Truncated responses are charged and persisted before one bounded expanded-cap retry; resume uses the persisted attempted cap.
- Tracked A/B configurations retain `budget_usd = 0`. Paid execution requires both `--execute-paid` and an explicit approved combined budget.

## Verification

- Offline suite: 57 tests expected after adding the experiment-confounder fault injection.
- `ab-run-development` without `--execute-paid` must return `paid_approval_required` with zero API calls.
- Blind-review export excludes protected units, hides arm identity in the public file and stores the reveal key separately.

## Promotion gate

Do not promote to stable `v0.6.0` from offline readiness alone. First obtain explicit approval for the CNY 1.50 paid ceiling, execute both development arms, complete blinded human review, and evaluate quality and actual cost. Frozen-test remains a later, separate decision.
