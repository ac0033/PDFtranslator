# v0.5.0-rc.1 semantic reconstruction acceptance

Date: 2026-09-11

## Scope

- Offline-only smoke run on physical pages 42, 51 and 577 of `dm.pdf`.
- No DeepSeek request was made and provider cost remained USD 0.
- The candidate covers semantic fragment grouping, coherent group translation, target-language layout resegmentation, exact short-text location and capture reuse.

## Automated evidence

- Test suite: 39 passed, including capture-reuse preflight and forward sentence-boundary placement guards.
- Captured fragments: 77; runtime units: 74.
- Billable paragraph units: 35; exact protected passthrough units: 39.
- Semantic groups: 3 groups / 6 source fragments, all on physical page 42.
- Layout boundary markers: 6; BabelDOC protected occurrences: 81.
- All 74 results reached `accepted`; every quality report passed.
- Source and translated marker order matched exactly for every aligned unit.
- All 39 protected units were byte-for-byte identical at the runtime boundary.
- A hot rerun left the ledger unchanged at 74 rows, USD 0 and zero provider tokens.
- Mono and dual artifacts both contain the expected three pages.

## Regression cases

- Physical page 42, section 2.2: `A probability distribution ... There are` and `different ways to represent ...` are translated as one semantic paragraph. The layout boundary is moved after the completed first sentence, so `There are` is no longer isolated.
- Physical page 42, section 2.2.1: two additional split paragraphs are grouped and resegmented without changing placeholder order.
- Physical page 51: exact page-text location yields one complete unit, `we can write the density function as a product of univariate Gaussian densities:`. No isolated `we can` unit remains.
- Physical page 577: the code panel remains protected and visually unchanged apart from the deterministic mock label outside protected source content.

## Visual review

All six rendered pages (mono and dual) were inspected at 150 DPI. The three regression cases above are readable, figures and equations remain present, and the merged artifacts have no missing pages. The offline provider intentionally prefixes translatable text with `[离线演示]`; these artifacts validate structure, not Chinese translation quality.

## Resource and upstream observations

- BabelDOC initially logged one font-allocation failure while the process was under peak memory pressure, then continued and completed all pages. The final merged PDFs opened and rendered successfully.
- The layout model now uses a bounded CPU session and is reused across page passes. Capture reuse defers loading it until injection.
- BabelDOC still logs `Failed to migrate TOC ... 'int' object is not iterable`; bookmark preservation is not accepted.
- 41 units have low-confidence region matches, mainly protected or non-prose material. Real Chinese output must still be reviewed for mixed-script spacing and formula-internal English.

## Cost gate for a later DeepSeek run

The captured workload estimate is 27,278 input tokens plus 70,000 reserved output tokens, for a configured maximum of USD 0.0921834. This is an upper-bound reservation, not an expected bill. The v0.5 DeepSeek configuration keeps `budget_usd = 0.0`; a new explicit RMB budget approval is required before execution.

## Verdict

The offline semantic reconstruction candidate is accepted as `v0.5.0-rc.1`. Real DeepSeek translation and Chinese visual QA remain a separate acceptance step.
