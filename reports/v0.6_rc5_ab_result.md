# v0.6.0-rc.5 development A/B result

## Outcome and limits

The paid development A/B completed on the frozen 12-page capture: 121 units per arm, including 117 billable translation units and 4 protected passthrough units. The two final r5 configurations and input hashes match `v0.6_ab_manifest_rc5.json`. Both arms use the same model, prompt, adapter, style, output policy and pricing; only neighboring source excerpts differ. Frozen-test was not opened.

This is a completed **execution** result, not yet an accepted translation-quality conclusion. The 117 anonymous X/Y pairs were exported locally, but the full human blind review is still unscored.

Those flags measure contract risks, not semantic translation quality. A small anonymous spot-check found both improved and nearly identical pairs; it is insufficient to declare a winner.

## Budget accounting

Final r5 combined ledger estimate: USD 0.0619071 / CNY 0.464303 at the fixed control rate of 7.5 CNY/USD. Including the incomplete diagnostic runs r1-r4, **all local ledgers total USD 0.1073217 / CNY 0.804913**, below the preferred CNY 1.5 and absolute CNY 2.0 limits. These amounts use returned token counts and configured unit prices; the provider's actual bill has not been independently reconciled.

## Diagnostic failures and safety response

1. r1/r2 exposed a deterministic layout-marker repair bug: a boundary-adjacent formula marker could jump past another formula marker. The relocation now stays between neighboring protected markers; the original failed output passes the corrected offline check.
2. r3 exposed legitimate Chinese formula reordering in a single layout slot. It is now `needs_review`, not a silent pass; cross-layout reordering remains blocked.
3. r4 exposed source/context contamination: while translating a copyright footer, the model returned neighboring paragraph text. The safety gate blocked it. r5 uses an explicit source-only prompt in both arms, and that exact footer translated alone and passed.

The diagnostic runs and their ledgers were retained under distinct run IDs; no accepted r5 result was copied from an earlier prompt revision.

## Next decision

Score the 117 local anonymous X/Y pairs for meaning accuracy, continuity, terminology, reference clarity and Chinese fluency, paying special attention to the 17 arm-level review alerts and short fragments. Reveal the arm key only after decisions are frozen. Stable `v0.6.0` and frozen-test access remain separate later gates.
