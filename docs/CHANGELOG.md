# Changelog

版本号规则见 `docs/versioning.md`。

## 0.8.0 — 2026-09-26 · 无人值守整本交付，14 页约 5 分钟

- 一条命令完成抽取、覆盖度核对、翻译、渲染、验收（`scripts/deliver_pdf.py`），各阶段耗时写入 `*.timings.json`；每个阶段可断点续跑。
- 翻译请求并发执行（配置项 `translation_concurrency`）；预算检查计入在途请求，账号或预算故障停止尚未发出的请求。该设置不影响运行身份，已有运行可直接提高并发续跑。
- 抽取与渲染按块分进程并行（`--workers`），按可提交内存自动限制进程数；抽取不再生成随后丢弃的 PDF；BabelDOC 字体文件每个进程只校验一次；本地翻译回调不再被限速。14 页讲义从约 23 分钟降到约 5 分钟，产出不变。
- 模型服务返回 HTTP 4xx（如余额不足）时整份文档暂停，不消耗单段重试次数、不虚记费用；同一运行加文件锁，防止两个进程同时写入。
- 只含页码的空白页直接放行；覆盖度检查不再把 Computer Modern 正文字体当成公式字体。
- 自动验收单：按问题对阅读的影响分级，漏译等大问题阻断交付；分诊、复核台账、捕获覆盖度对账。
- `scripts/apply_local_fixes.py`：把人工核对后的译文（含从未译出的段落）写回任意运行，只重渲染受影响的页，不调用模型。
- 仓库只保留产品文件；版本号在 `pyproject.toml` 与包内一致，由 `tests/test_public_hygiene.py` 守住。
