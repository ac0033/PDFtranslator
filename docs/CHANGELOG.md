# Changelog

版本号规则见 `docs/versioning.md`。

## 未发布

- **漏译一处即阻断交付**：译文仍是英文句子的单元（`untranslated_unit`）不再按 5% 阈值计为小问题，只要有一处未被复核台账放行，就判为 `not_deliverable`。验收单的 `thresholds.zero_tolerance` 会列出这类不设阈值的类别，阈值覆盖对它们无效。
- **漏译检测只抓真正的英文句子**：译文要剩下至少两个英文虚词（the、of、and……）才会被判为漏译；单字母变量和人名缩写、原文自己引用的英文句子也不再计入。在 3 本已译书上核对，原先 33 处误报（SQL 代码、公式、作者名单、索引、示例串、引用的例句）降到 1 处（图中保留的一句英文广告语）；整段英文、半句未译、引号包起来的未译句子仍能检出。

## 0.10.0 — 2026-09-27 · OpenAPI 描述与接入修复

- HTTP 服务提供 OpenAPI 3.1 描述：`GET /v1/openapi.json`。参数说明与 MCP 工具共用同一份定义，测试保证两者和实际路由一致。
- 通过 MCP stdio 提交的任务，翻译进程不再继承服务的标准输入，避免它读走客户端发来的 JSON-RPC 消息。
- `httpx`（远程客户端用）改为显式依赖。

## 0.9.0 — 2026-09-26 · 任意模型、排版复核、对外接入

- **换用任意大模型**：配置里的 `provider` 选一个预设即可（DeepSeek、OpenAI、Claude、Gemini、通义千问、Kimi、智谱、豆包、硅基流动、OpenRouter、Groq、Mistral、xAI、Ollama，以及任何兼容 OpenAI 接口的服务；装上 LiteLLM 后还可用它支持的全部模型）。翻译、告警复核、排版复核都走同一个调用层；服务不支持指定的结构化输出方式时自动降一级，返回的 JSON 始终在本地校验。已有运行的身份不变，可直接续跑。
- **排版复核**：渲染后把每页原图、译图和该页各段交给模型，找出中英文对不上的地方（原页看不见的隐藏文字混入正文、伪代码被译成散文、符号错位、译文被挤小）并给出替换译文。替换必须通过质量门、不带来新问题、不改动公式、不编造英文、不借修正改写原意，才会写回；只重渲染改动的页。费用计入同一预算，账户被拒（401/402/403）时停止其余页。
- **对外接入**：翻译以“任务”为单位，通过命令行（`pdftrans translate / jobs`）、HTTP 服务（`pdftrans serve`）、MCP（本机 stdio 与远程 HTTP）和 Claude Skill 提供，本机和任意主机都能调用。监听本机以外的地址必须设令牌；随任务传入的模型 Key 只在内存中使用，不写入磁盘；远程调用方不能指定服务器上的文件。
- **接入方可以继续修改已完成的任务**：读取单元（`get_units`）、委托本任务的模型做一件事（`ask_model`：重译、压缩、复核单元、对照页面图像复核、自由提问；先估价、计入任务预算和账本、只返回候选修正）、写回修正（`apply_fixes`：整批校验，只重渲染改动的页并重新验收，不调用模型）。
- **失败或取消的任务可以续跑**（`resume_job`）：已抽取的内容和已付费的译文直接复用。修复了 `deliver_pdf.py` 重跑时因抽取结果已存在而失败的问题。
- `docs/agent_guide.md`：给接入的工具和 AI agent 的完整说明——流程、每个文件和字段、验收结论怎么读、何时自己处理、何时委托模型、出问题怎么办。MCP 以资源形式提供，HTTP 为 `GET /v1/guide`，命令行为 `pdftrans guide`。
- 渲染只启动仍缺页面的分块，重渲染几页不再为每个分块加载版面模型。
- 漏译检查不再把中文译文里保留的人名、缩写（原文中大写的词）算作残留英文。此前短文档会因作者名单、关键词行被误判为不可交付；阈值不变，整段英文和中文夹杂的英文句子照常判为漏译。在 4 本已译书上核对，被排除的全部是正确译文。

## 0.8.0 — 2026-09-26 · 无人值守整本交付，14 页约 5 分钟

- 一条命令完成抽取、覆盖度核对、翻译、渲染、验收（`scripts/deliver_pdf.py`），各阶段耗时写入 `*.timings.json`；每个阶段可断点续跑。
- 翻译请求并发执行（配置项 `translation_concurrency`）；预算检查计入在途请求，账号或预算故障停止尚未发出的请求。该设置不影响运行身份，已有运行可直接提高并发续跑。
- 抽取与渲染按块分进程并行（`--workers`），按可提交内存自动限制进程数；抽取不再生成随后丢弃的 PDF；BabelDOC 字体文件每个进程只校验一次；本地翻译回调不再被限速。14 页讲义从约 23 分钟降到约 5 分钟，产出不变。
- 模型服务返回 HTTP 4xx（如余额不足）时整份文档暂停，不消耗单段重试次数、不虚记费用；同一运行加文件锁，防止两个进程同时写入。
- 只含页码的空白页直接放行；覆盖度检查不再把 Computer Modern 正文字体当成公式字体。
- 自动验收单：按问题对阅读的影响分级，漏译等大问题阻断交付；分诊、复核台账、捕获覆盖度对账。
- `scripts/apply_local_fixes.py`：把人工核对后的译文（含从未译出的段落）写回任意运行，只重渲染受影响的页，不调用模型。
- 仓库只保留产品文件；版本号在 `pyproject.toml` 与包内一致，由 `tests/test_public_hygiene.py` 守住。
