## 成本与方法

官方 DeepSeek 定价页于本轮读取：deepseek-flash；保守按高峰未缓存输入 0.30 美元/百万 token、输出 1.20 美元/百万 token 估算，实际以 API 记录核对（实际单价低于估算，缓存命中生效）。配置使用 val 独立上下文（runs/val-usable/context.sqlite），未复用旧 CS224n 文档术语库。

BabelDOC 为已安装依赖，官方仓库标注 AGPL-3.0。本轮验证了 0.6.4 版本实际效果，未做升级。轻微像素差异保留诊断记录，不自动当作不可交付。

## 本轮管线修复（均有回归测试）

1. `retry_feedback_request`（pipeline.py）：质量失败重试时把被拒译文与具体失败原因作为纠正反馈附加进请求，替代原样盲重试。
2. 重试成功的结果通过 `StateStore.alias_cache_key` 回指首次请求的缓存键，避免重跑时状态被重置导致重复付费调用。
3. `capture_pdf_sample` 跳过经 pymupdf 验证为完全空白的页并记录 empty_pages；回写时空页原样插入，保证页码对应。
4. `layout_boundaries_are_natural` 允许数字结尾的段（目录/索引页码行）。
5. `ProviderAttemptsExhausted` 携带 unit_id；`run_smoke_document` 标记耗尽单元为 exhausted 并继续其余单元，渲染门按既有规则阻断直到补齐；有翻译记忆条目的耗尽单元可被恢复处理。
6. scripts/capture_val_full.py 分块可续跑全书捕获；scripts/render_val_full.py 分块子进程渲染 + 页级断点 + --merge-only 合并。
